# dsh-bili-ghost

AI 干活的时候，右下角弹一个小窗，优先放 B 站编辑精选（每周必看 / 入站必看），再用当天的优质鬼畜补满；这一轮结束，窗口和声音一起消失。

## 它做什么

- **AI 工作时自动出现**：检测当前可见会话是否在跑。为了不被秒回的任务闪一下，窗口会等约 1.2 秒才出现。
- **优先放编辑精选**：Host 半边先取「每周必看」最新一期和「入站必看」合集，鬼畜 / 搞笑分区排在最前；不够 20 条时，用鬼畜区（分区 119）当天投稿按「播放 + 点赞×4 + 投币×6 + 收藏×6 + 弹幕 + 评论 + 转发×3」排序补满。
- **当天没投稿时的降级**：用当天 0 条时改放**最新投稿**（不是"最近热门"），角标显示「最新投稿」；精选存在时角标显示「编辑部精选」。
- **AI 结束自动关闭**：会话从 running 变回 idle 时窗口直接卸载，iframe 被移除，声音立即停止，不会留一个后台播放器。
- **可拖动**：按住标题栏拖动，位置记在 `localStorage`，窗口尺寸变化时自动夹回视口；标题栏右侧有 `⠿` 把手。
- **可以换片 / 停止 / 收起**：「换一个」轮换片单并自动恢复播放；「停止播放」重载播放器、停止自动播放，再点「重新播放」从头开始（跨源 iframe 无法续播到原进度）；`Esc` 或「暂时收起」把窗口收成右下角的小幽灵按钮，随时点回来。

## 为什么需要 Host 半边

B 站的排行榜接口不允许浏览器跨域直接调用，而且对 UA / Referer 有要求；「每周必看」单期接口还要求 wbi 签名。所以插件在 DSH 自己的 web server 上注册了同源只读路由：

```
GET /__bili-ghost/feed
```

路由只接受同源的可信浏览器请求（`connection.requestRejection` 鉴权），只允许 GET / HEAD，5 分钟缓存，B 站暂时不可用时返回上一次的缓存片单。页面本身不直接访问 B 站接口。

## 安装

在 DSH 里把本目录作为 bundle 安装：

```
plugin_manager install_bundle  target = <本目录的绝对路径>
```

安装后客户端入口通过 `dsh.client` 清单加载。如果页面里没出现，刷新一次 Web GUI；如果路由 404，重启 DSH 让 Host 半边生效。

## 数据与隐私

- 只向 `api.bilibili.com` 请求公开的投稿 / 合集列表，不发送任何本地会话内容。
- 播放器是 B 站官方的 `player.bilibili.com` iframe，播放行为受 B 站自身隐私政策约束。
- 片单只在内存里缓存 5 分钟，不落盘。

## 已知限制

- 浏览器可能拦截带声音的自动播放。DSH 页面通常在用户输入过之后才跑任务，多数情况下没问题；若被拦截，点一下播放器里的播放键即可。
- 视频能否播放取决于 B 站（分区、版权、地区限制）；个别稿件可能显示「视频去哪了呢」。
- 若你在另一个会话里跑任务、当前会话空闲，窗口不出现（只跟随主视图里可见的会话）；设置页等面板打开时，主会话仍在跑，窗口仍会保留（它只是浮在最上层，不挡操作）。
- 浮窗的 z-index 只比应用内容高一层，弹窗、右键菜单会盖住它——这是有意为之，避免挡住需要你确认的对话框。
- 界面文案在 `client.js` 的 `DICTS` 里（zh / en 两套，运行时注册）；`locale/*.json` 是插件列表的元数据，两处需要同步改。
- 没有在真实浏览器里做自动化视觉验证；已通过清单、语法、路由和 slot 注册检查。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 半边：`/__bili-ghost/feed` 路由、wbi 签名、抓取、筛选、打分、缓存 |
| `client.js` | Client 半边：`shell.overlay` 浮窗、拖动、portal 到 body、播放器 iframe |
| `locale/*.json` | 插件列表里的标题与描述 |
| `cordis.patch.yml` | bundle 的注册补丁 |
| `icon.svg` | 插件图标 |
